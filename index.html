Komprehensif Materi Pembelajaran KKA

Berdasarkan modul pembelajaran Bab 3 Koding dan Kecerdasan Artifisial.

1. Tiga Jenis Algoritma Utama

Search Algorithms

Mencari elemen tertentu dalam array.
• Linear: Memeriksa tiap elemen satu per satu.
• Binary: Membagi array terurut menjadi dua bagian ($O(\log n)$).

Sorting Algorithms

Menyusun data terurut.
• Bubble Sort: Menukar elemen berdekatan.
• Selection Sort: Memilih elemen terkecil ditukar ke awal.
• Quick Sort: Membagi data via pivot secara rekursif.

Classification (ML)

Mengklasifikasikan data ke kategori tertentu.
• KNN
• SVM
• Random Forest

2. Kinerja & Kompleksitas Algoritma

Parameter Kinerja:
  • Waktu Eksekusi (Time Complexity): Waktu menyelesaikan tugas berdasarkan operasi dasar.
  • Penggunaan Memori (Space Complexity): Ruang penyimpanan yang dibutuhkan.
  • Akurasi: Sejauh mana hasil algoritma mendekati solusi sebenarnya.
Contoh Penerapan Nyata Machine Learning:

• Rekomendasi Konten: Netflix/YouTube menggunakan Collaborative Filtering.
• Sistem Pengenalan Suara: Google Assistant/Siri.
• Kendaraan Otonom: CNN & Reinforcement Learning.
